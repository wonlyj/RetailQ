# 第四章口语问题误拒答修正设计

2026-11-05 用户确认：“确认按这份草案实施”。

## 目标和约束

修复有充分知识却被过高的重排门槛拒绝的问题，包括用户反馈的“邮费咋算，买不到免邮门槛要加多少？”。继续使用 Milvus 原生 BM25、dense + RRF、BGE reranker、来源引用、生成模型的证据充分性自评和低置信度问题池。不改入库侧同义词策略，不增加多轮改写；保持明确拒答及禁止承诺到账时间。

## 已有证据和限制

- 同问复测中，正确运费条款在 dense、BM25 和混合重排结果均排第一；重排首分约 0.4075，现有阈值约 0.9582，因而被检索门槛拒绝。历史请求没有保存候选分数，不能将复测数值说成历史数值。
- 现有 20 题校准把不可回答问题作为相关性负样本。4 个缺失具体型号属性的问题首分约 0.56–0.92，但其相同型号的其他知识本来就可能高度相关；有完整证据的口语校准题分数则低至约 0.03。单个分数无法直接判断问题能否回答。
- 原 80 题测试集及用户反馈已被查看，不再作为新门槛的独立保留集。已有自动裁判不等于人工事实审查。

## 比较方案

1. **直接下调现有数值**：改动最少，但用已暴露的例子选数会过拟合，且不能证明缺失属性仍能拒答，不采用。
2. **以标注区分检索相关性和证据充分性，重新校准，并保留生成自评（推荐）**：用新标注样本评价召回片段是否相关，不把“属性缺失”等价为“不相关”；生成自评单独判断能否回答。用新保留集测试漏答、错误回答、引用与缺失入池。仍保留标定的确定性相关性门槛和空召回拒答，符合原设计。
3. **只要有候选就交给生成模型判断**：可以避免分数门槛误拒，但取消已批准的相关性门槛，且把防护过度集中于模型自评，不采用。

## 推荐方案的实施和验收

1. 先冻结新的样本清单和按问题族划分的校准/独立测试：覆盖口语同义词、型号与相近型号、知识缺失但文本相关、完全无关、需要多段证据和不能承诺的政策；为候选相关性和能否完整回答分别标注，并保留判断依据与可回溯的来源。邮费反馈作为已知回归题，不能计入独立测试。不同切分不得共享改写族；冻结后不得用保留集回调门槛。
2. 先以标注样例验证校准规则；测试先行修改校准逻辑与数据校验，确保未知/缺失标签不会静默当成负例、每种策略分数单独拟合、身份漂移仍拒绝加载。必要时扩展身份以绑定检索与标注规则的变化，防止使用旧门槛。
3. 在隔离环境调用真实 embedding、Milvus、重排与生成服务，保存每一轮数据和错误；先校准并冻结门槛，再运行新独立测试。输出可答题误拒、缺失题错误作答、无关题拦截、引用正确性及低置信度入池，逐类列出分母；对错误回答与风险边界做人工核对。真实服务不可用时报告阻塞，不用模拟结果代替。
4. 先回归原邮费问题、具体型号、完全无知识、缺失型号属性、禁止承诺、引用和原文；再跑项目完整测试及真实聊天链路。若独立测试显示错误作答风险不可接受，则不发布新门槛，保留原因和原配置。
5. 经代码审查与验证后才替换隔离运行环境的校准文件；保留原文件和旧报告，不重建或删除既有数据。测试指南中的运行参数如需调整，提供可复制的更新命令；用户数据与演示环境不自动迁移。

具体相关性标注标准、样本规模、门槛选取规则及各类指标的最低验收线应在编写计划时明确，不能依据新测试结果事后更改。若标注不足以稳定选择门槛，保持原门槛并报告限制，不伪造通过结果。
