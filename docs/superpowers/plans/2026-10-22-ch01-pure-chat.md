# RetailQ 第 1 章纯对话客服 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现可由 curl 验收的 SSE 多轮客服与售后 JSON 提取，并留下代码测试、Prompt 评估和 Git 过程证据。

**Architecture:** 客户端携带完整历史，FastAPI 校验后经模板渲染、预算裁剪调用统一的 ChatOpenAI 适配器。服务端不保存会话，不执行工具；对话逐上游文本增量转为 SSE，提取使用无工具的 with_structured_output。

**Tech Stack:** Python 3.13.9、FastAPI、LangChain（langchain-core / langchain-openai）、Pydantic / pydantic-settings；pytest、AnyIO asyncio 后端、HTTPX、Uvicorn。在项目 `.venv` 安装并锁定实现时核实的稳定版本，不提前宣称具体版本兼容。

**Spec:** `docs/superpowers/specs/2026-10-22-ch01-pure-chat-design.md`（2026-10-22 用户批准，包含后补人设 / 红线）。

**Status:** 计划草案已完成自查，待用户评审和选择执行方式；下列任务均未执行。

## Global Constraints

- Python + FastAPI + LangChain；应用只使用 OpenAI Chat Completions 协议，直连配置的上游；地址、模型和密钥通过 `.env` 配置。
- 方案 A：客户端携带历史；不实现工具调用、Agent 循环、RAG、订单查询、退款执行、数据库、服务端会话持久化、登录或部署平台。
- 默认 `CONTEXT_WINDOW_TOKENS=8192`、`MAX_OUTPUT_TOKENS=1024`、`TOKEN_SAFETY_MARGIN=512`、`MODEL_TIMEOUT_SECONDS=60`；输入预算 6656。上下文窗口由部署者按实际模型填写。
- 文本上限 8000 个 Unicode 字符；history 最多 100 条，仅 user / assistant 完整交替轮次；未知字段拒绝。
- `STRUCTURED_OUTPUT_METHOD` 仅允许 `json_mode`（默认）或 `json_schema`；显式传 method，不用 function_calling，不绑定工具；不兼容时停下询问，不静默换方案。
- 用户人设原文按 spec 实现；退款政策表述统一为「以平台售后规则为准」；不得虚构查询结果、赔偿、时效或已完成的人工转接。
- SSE 事件为 meta / token / done / error，data 为 JSON；token 事件转发真实上游非空文本增量，不保证单事件恰好一个 token。
- 代码任务 TDD；纯 Prompt / 数据任务用标注样例评估；没有真实上游配置时如实标记未验收，不能拿 mock 通过代替模型能力。
- 后续如新增聊天页面，按用户要求使用 Vibe Coding，页面不套本计划的 brainstorm / TDD / code review 流程。
- 每任务结束即时追记 `dev-notes/ch01.md` 的四项：用户关键原话、产出与评审结论、拒绝或纠偏、翻车与返工；之后单独提交本地 Git。未经指示不推送远程。

## Review Focus

1. 中文、emoji、花括号和单条超长文本：预算不漏算，不二次解释模板，不删当前问题或 System Prompt（任务 1 / 2）。
2. 裁剪边缘的孤立 assistant、100 条历史和新旧订单指代：只保留最近完整轮次，不跨会话串信息（任务 1 / 2 / 4）。
3. 首 token 前超时、部分输出后断开、上游空输出及截断：错误 / 结束语义正确，及时关闭上游，不泄露异常或重复重试（任务 3 / 4）。
4. 兼容端点拒绝 response_format、返回工具调用、缺字段 / 多字段 JSON：明确失败，不偷偷降级、不把非法结构当成功（任务 3 / 5）。
5. 用户要求编代码、保证赔偿、查询实时价格或声称已退款：真人设约束通过标注样例检验，不以模板关键词存在代替效果（任务 2 / 6）。
